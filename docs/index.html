03 / Why the loop matters

The right answer.
The wrong moment.

A response can be correct about the past
and unhelpful in the present.

STALE GUIDANCE

The user has already moved on.

“Don't serve that plate. Go to the trash…”Assistant · tick 56
“Already did that.”User · tick 56

Advice to discard the raw fish arrives after the user has already cleared the plate. An evolving world makes timing part of correctness.

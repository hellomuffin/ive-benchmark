IVE Interactive Visual Evaluation

A benchmark for closed-loop visual assistance

We evaluate visual assistants that observe a user’s ongoing activity and provide guidance during task execution. Built on Interactive Visual Gym, IVE jointly simulates task environments and human users to measure how assistance affects task outcomes and interaction quality.

Evaluation and submission

Submission tools are available in preview. Verified leaderboard inclusion requires trace and score review.

1

Explore the benchmark

The replay kit includes the three demonstrations, recorded dialogue, and evaluation data. It runs locally without an API key or GPU; it does not execute new benchmark episodes.

Download replay kit ↓Code & instructions ↗
2

Validate a submission

Provide a versioned manifest for all three environments and three independent runs. Checks verify case–persona membership and trace metadata. Files are checked locally in your browser.

Example manifest ↓JSON schema ↓


3
Submit results
Open a pull request with your manifest and links to execution traces. Automated checks validate the submission structure; they do not verify scores or automatically publish a leaderboard entry.

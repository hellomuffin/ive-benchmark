IVE Interactive Visual Evaluation

A benchmark for closed-loop visual assistance

We evaluate visual assistants that observe a user’s ongoing activity and provide guidance during task execution. Built on Interactive Visual Gym, IVE jointly simulates task environments and human users to measure how assistance affects task outcomes and interaction quality.

Evaluation protocol

IVE contains 105 task cases, each paired with three user personas: 150 cooking, 75 household, and 90 mobile-interface episodes. We evaluate each assistant over three independent runs.

Required episodes and runs →Case–persona catalog ↓

Report reproducible results

Identify the model version and include execution traces for every case–persona episode. Retain event coverage counts, since assistants may reach different subsets of scheduled events.
